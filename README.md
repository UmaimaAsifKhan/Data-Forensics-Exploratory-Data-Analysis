# Data-Forensics-Exploratory-Data-Analysis
Project Overview
This project focuses on Exploratory Data Analysis (EDA) and Data Forensics on a sales dataset. The primary goal was to identify inconsistencies in coupon code tracking and improve overall data integrity for better business decision-making.

Key Objectives
Data Cleaning: Handling duplicates and normalizing inconsistent text entries.

Forensic Analysis: Investigating the 25% missing values ("Unknown") in coupon codes to understand tracking gaps.

Statistical Analysis: Using the IQR (Interquartile Range) method to identify and mitigate outliers.

Actionable Insights: Providing data-backed recommendations to optimize the checkout funnel.

Technical Skills Used
Data Analysis: Python (Pandas, Matplotlib/Seaborn).

Data Integrity: Forensic auditing, Standardization, Imputation.

Tools: MS Excel, GitHub for version control.
